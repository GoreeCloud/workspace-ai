# Saved Prompts

Workspace AI now supports browser-local prompt templates. Use Prompts in the sidebar to create, edit, search, delete, and reuse prompts in chats and Projects. Global prompts can be used everywhere; Project-only prompts may only be inserted into their assigned Project.

Using a prompt populates a draft but never sends it automatically. The composer also offers a Saved prompts menu. Up to 100 prompts, with a 100-character title and 12,000-character body, may be stored. Existing JSON workspace backups include prompts. Project deletion removes Project-specific prompts, and backup merge cannot attach incoming private prompts to a different preexisting Project with the same ID.

All data remains in local browser storage and may be lost if that storage is cleared. No cross-device sync, provider writes or MCP permissions are activated by saving or using a prompt. Live-device and production acceptance remain unverified.
